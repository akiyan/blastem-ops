# 停止中の速度設定と work RAM 観測

## 速度設定

通常の MD を停止中に MCP の `speed_set {"percent": 1000}` を呼ぶと、既存の速度変更機能を使ってホスト上の進行速度を変える。

- 25〜1000% を受け付ける。等速に戻すには 100
- CPU サイクルやフレームを省略する機能ではない。指定したフレーム数は速度にかかわらず守られる
- 実際の倍率はホスト性能に依存する。音声の resampling も変わるため、音声を評価するときは 100 に戻す
- GDB セッション、CD・32X、threaded video では使えない

## work RAM 観測

`ram_read {"address": 16711680, "size": 16}` は、停止したフレーム境界で MD の 64 KiB work RAM（`FF0000..FFFFFF`）から 1〜256 バイトを読み取る。

- CPU のメモリバスを呼ばず、ホスト上の work RAM 配列をアドレス順の hex に変換する。I/O の副作用や CPU の実行を伴わない
- I/O・ROM・Z80 空間は読めない
- 応答には `frame` を含める。画像は別途「最後に描画を完了したフレーム」なので、同じサイクルの RAM と画面を一括で取得する保証はない

## 本体

capability は `speed_control` と `paused_work_ram`。パラメーター不正と動作中の要求は拒否する。フレーム進行中は既存の busy 規則に従う。

## 試験

- 本体で 25・500・1000・100% に変え、それぞれ6フレームの進行数を確認する
- RAM の範囲外、境界越え、未停止の拒否、非整列の読出し、繰り返し読み出しても値が変わらないことを確認する
- fixture の既知値 `11223344` について、奇数アドレスからの3バイトが `223344` になることを本体と MCP の両方で確認する
- 速度を 100 に戻した後に PSG 音を録音できることを確認する
